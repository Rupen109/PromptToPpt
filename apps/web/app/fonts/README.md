# Fonts (self-hosted)

Latin subset, variable woff2, downloaded from Google Fonts (all four are under the SIL Open Font License, so they may be bundled).
They are kept in the repository so the build never has to reach Google (the Docker build in GitHub Actions could not).

| File | Family | Weights used |
|---|---|---|
| Inter-latin.woff2 | Inter | 400, 600, 700 |
| PlusJakartaSans-latin.woff2 | Plus Jakarta Sans | 700, 800 |
| Sora-latin.woff2 | Sora (wordmark only) | 300, 800 |
| Caveat-latin.woff2 | Caveat | 700 |
